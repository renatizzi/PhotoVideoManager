1. Decisione sul flusso lineare (punto «valutare»)

Raccomandazione: sì, compattare. Nella guida (videata ramo) resta l’accordion delle 4 fasi + icona stampa. La conferma avviene una fase alla volta sotto la fase corrente (messaggio + OK + esito checkpoint), senza una seconda pagina di riepilogo monolitica. Se serve ancora una pagina «Riepilogo e conferma» come rete di sicurezza, resta opzionale/collassata; nel TO-BE primario non è una tappa obbligatoria separata.
Avvio→ Verifica→ Scelta modalità→ Guida ramo (4 fasi accordion + conferma 1×1)→ Import DATI_CIFS→ Copia CIFS

8. Criteri di accettazione v3 (prima del codice)

  1. Nessuna lettera A/B/C né numerazione progressiva sulle opzioni/fasi guida (titoli autoconsistenti).
  2. Terminologia: sempre «Telefono» (mai «dispositivo mobile» / «telefono/tablet»).
  3. Topbar consolidata: MediaManager | Setup.
  4. Tre rami con stesso scheletro; 4 fasi; stampa solo icona in descrizione.
  5. Conferma lineare una fase alla volta + esito checkpoint sotto OK; CONFERMA in fondo.
  6. Messaggi conferma letterali (4) senza citare BT/USB.
  7. File: DATI_CIFS.json / no_pw.json; overwrite Desktop.
  8. Import + CIFS semplificati (come Ottimizzazione).
