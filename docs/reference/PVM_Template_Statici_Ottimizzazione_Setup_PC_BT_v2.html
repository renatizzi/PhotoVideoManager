Setup Catalogo personale

Associazione con Bluetooth del dispositivo mobile e pc

Procedura semiautomatica. Tocca un punto per leggerlo. La stampa è solo un aiuto.

1. Invia i 3 file al PC▾
Nel popup Condividi scegli l’opzione che invia al PC (es. Bluetooth / Collegamento…). Conferma sul nome del PC.
2. Conferma invio▸
Clicca sul nome dispositivo proposto nella videata successiva.
3. Dove sono i file sul PC▸
Di solito Download. Altrimenti Impostazioni Windows → Bluetooth → Dispositivi mobili → cartella trasferimenti.
4. Copia sul Desktop▸
Copia i 3 file ricevuti sul Desktop (unica versione / overwrite).
5. Lancia CONFIGURA▸
Doppio clic CONFIGURA → attendi «Tutto pronto» (verde). Non interrompere.
6. Invia DATI_CIFS.json al telefono▸
Solo quel file. BT classico; Phone Link opzionale se già attivo. Ignora no_pw.json.
7. Torna all’app▸
Non restare sulla pagina Invio/Ricevi di sistema: torna a MediaManager.

5. Criteri di accettazione aggiornati

  1. Guida completa leggibile sul telefono (accordion); stampa non obbligatoria.
  2. Un solo punto accordion aperto di default / tap per espandere — evita muro di testo.
  3. Riepilogo: unica pagina con 3 fasi (flag auto + OK + Indietro fase); piede Annulla | CONFERMA.
  4. CONFERMA attiva solo con tutte le fasi flaggate; Annulla → ingresso Associazione.
  5. Rami B e C: stesso layout di A; solo testi accordion diversi.
  6. File: DATI_CIFS.json da importare; no_pw.json da ignorare.
  7. Import/CIFS come v1 (semplificati).
