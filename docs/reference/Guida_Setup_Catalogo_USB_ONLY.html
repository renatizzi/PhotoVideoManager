Setup del Catalogo personale — solo USB

Procedura di collegamento e trasferimento file tra Telefono Android e PC Windows tramite cavo USB. La procedura prepara il PC come sede del Catalogo e trasferisce a MediaManager i dati per configurare CIFS.

Versione guida: USB-only · specifica Cursor REV4 (7 fasi) · 23/11/2026 (Europe/Rome)

Le 7 fasi della procedura

1Creazione file di configurazione
2Invio script al PC
3Esecuzione script sul PC
4Invio dati CIFS al Telefono
5Import dati CIFS
6Installa / Apri CIFS
7Configura CIFS e attiva Catalogo

In app: una fase per pagina; avanzamento dal titolo della fase. Guida sempre dal link «L’intera guida può essere stampata qui» 🖨. Annulla riparte da Avvio (azzera i checkpoint).

Prima di iniziare

  • Dispositivo mobile con l’app MediaManager installata.
  • PC/Notebook Windows 10 o superiore.
  • Cavo USB che supporta il trasferimento dati (non solo ricarica).

Collegamento fisico USB

Predisponi il collegamento con un cavo USB tra il Telefono e il PC.

Cosa fare:

  1. Collega il Telefono al PC con un cavo USB che supporti il trasferimento dati. Mantieni entrambi i dispositivi accesi e sbloccati.
  2. Sul Telefono, scorri dall’alto verso il basso per aprire il pannello delle notifiche. Apri la notifica relativa alle impostazioni USB.
  3. Seleziona «Trasferimento di file» (o «Trasferimento file/MTP») al posto di «Solo ricarica» e autorizza l’accesso ai dati, se richiesto.

Fase 1 — Creazione file di configurazione

  • Fase gestita dall’app dopo la tua conferma.
  • Saranno creati nella cartella Download del Telefono i file (script) necessari per configurare la cartella del Catalogo personale.
  • In app tocca Pronto. Non passare alla Fase 2 se la generazione non ha esito positivo.
Esito: in Download compaiono CONFIGURA.CMD, QRCoder.dll e sup.ps1.

Fase 2 — Invio script al PC

  • Fase gestita manualmente dall’utente.
  • I file creati da inviare al PC sono tre: CONFIGURA.CMD, QRCoder.dll e sup.ps1.
  • Sul Telefono apri File/Archivio → Memoria interna → Download. Seleziona e copia i tre file.
  • Sul PC apri Esplora file → Questo PC → Nome del Telefono → Memoria interna → Download. Seleziona i tre file e copiali sul Desktop del PC.
Esito: i tre file sono sul Desktop. In app tocca Fatto. Non eseguire ancora lo script.

Fase 3 — Esecuzione script sul PC

  • Fase gestita manualmente dall’utente.
  • Sul PC apri Esplora file → Questo PC → Desktop. Seleziona CONFIGURA.CMD e avvialo con doppio clic.
  • Segui le istruzioni e attendi «Tutto pronto».
  • Lo script crea no_pw.json e DATI_CIFS.json. Solo DATI_CIFS.json andrà al Telefono.
Esito: DATI_CIFS.json sul Desktop. In app tocca Fatto.

Fase 4 — Invio dati CIFS al Telefono

  • Fase gestita manualmente dall’utente.
  • Sul PC: Desktop → individua DATI_CIFS.json.
  • Copia DATI_CIFS.json nella memoria interna del Telefono → Download (via USB).
  • Non trasferire no_pw.json.
Esito: DATI_CIFS.json in Download del Telefono. In app tocca Fatto.

Fase 5 — Import dati CIFS

  • Fase gestita dall’app dopo la conferma dell’utente.
  • Premi «Importa dati CIFS» e seleziona DATI_CIFS.json tramite il selettore file.
  • MediaManager legge e interpreta il file. Dopo import OK, tocca Fatto.

Fase 6 — Installa / Apri CIFS

  • Installa o apri CIFS Documents Provider.
  • Al termine torna a MediaManager e conferma con Fatto (checkpoint: app presente).

Fase 7 — Configura CIFS e attiva Catalogo

  1. Apri CIFS → premi [+] → seleziona «Input».
  2. Torna a MediaManager.
  3. Per ogni campo: «Copia» in MediaManager → incolla nel campo corrispondente in CIFS.
  4. Ripeti fino a completare tutti i campi richiesti.
  5. Salva in CIFS e verifica che la cartella condivisa sia nell’elenco.
  6. Torna a MediaManager, conferma di aver salvato, poi premi «Attiva Catalogo».
Esito: cartella visibile in CIFS; in Riepilogo «Catalogo creato correttamente» solo se l’attivazione è reale.

Controllo finale

  • Trasferimenti solo via cavo USB (niente Bluetooth / Wi‑Fi / Phone Link nel setup).
  • Sette fasi separate completate con i relativi checkpoint.
  • DATI_CIFS.json della sessione corrente importato.
  • Catalogo attivato in MediaManager.
