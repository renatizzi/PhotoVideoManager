Setup del Catalogo personale — solo USB

Procedura di collegamento e trasferimento file tra Telefono Android e PC Windows tramite cavo USB. La procedura prepara il PC come sede del Catalogo e trasferisce a MediaManager i dati per configurare CIFS.

Versione guida: USB-only · allineata a ripristino USB2.3 (6 fasi) · 21/11/2026

Le 6 fasi della procedura

1. Creazione scriptsul Telefono
2. Invio scriptal PC (USB)
3. Esecuzione scriptsul PC
4. Invio dati CIFSal Telefono (USB)
5. Import dati CIFSsul Telefono
6. Configurazione CIFSsul Telefono

In app: una fase (o coppia coerente) alla volta; fase corrente evidenziata. Guida sempre disponibile dal link «qui» 🖨.

Prima di iniziare

  • Telefono con MediaManager già installato.
  • PC/Notebook Windows 10 o superiore.
  • Cavo USB che supporta il trasferimento dati (non solo ricarica).

I nomi dei menu possono variare leggermente; le cartelle indicate (Download, Desktop) sono quelle da usare.

Collegamento fisico USB

  1. Collega il Telefono al PC con il cavo dati e mantieni il Telefono sbloccato.
  2. Nella notifica USB del Telefono passa da «Solo ricarica» a «Trasferimento file» / MTP e autorizza l’accesso ai dati.

Fase 1 — Creazione script sul Telefono

Obiettivo: far creare all’app i file necessari allo script Windows.

  • In MediaManager, Setup Catalogo → conferma prerequisiti → avvia la procedura USB.
  • Nella Fase 1 tocca Pronto: l’app crea in Download i file CONFIGURA.CMD, QRCoder.dll, sup.ps1.
  • Se la creazione non riesce, segui il messaggio a video e riprova.
Esito: i tre file sono nella cartella Download del Telefono (unica versione, senza (1)/(2)).

Fase 2 — Invio script al PC

Obiettivo: portare i tre file sul Desktop del PC via USB.

  • Sul PC: Esplora file → Questo PC → nome del Telefono → Memoria interna → Download.
  • Seleziona e copia: CONFIGURA.CMD, QRCoder.dll, sup.ps1.
  • Incolla sul Desktop del PC (sostituisci eventuali copie precedenti).
Esito: i tre file sono sul Desktop. Poi in app tocca Fatto.

Fase 3 — Esecuzione script sul PC

Obiettivo: predisporre la cartella condivisa e generare i dati CIFS.

  • Sul Desktop: doppio clic su CONFIGURA.CMD e conferma UAC se richiesto.
  • Non chiudere la finestra; attendi il messaggio «Tutto pronto».
  • Lo script crea DATI_CIFS.json (da usare) e no_pw.json (da ignorare).
Esito: DATI_CIFS.json presente sul Desktop. In app tocca Fatto.

Fase 4 — Invio dati CIFS al Telefono

Obiettivo: copiare sul Telefono solo il file generato dallo script. Bottone app: Fatto.

  • Con il cavo ancora in Trasferimento file / MTP:
  • Dal Desktop del PC copia DATI_CIFS.json nella cartella Download del Telefono.
  • Non usare no_pw.json né file con nome DATI_CIFS (1).json.
Esito: DATI_CIFS.json in Download del Telefono.

Fase 5 — Import dati CIFS sul Telefono

Obiettivo: far leggere a MediaManager il JSON della sessione corrente. Bottone app: Fatto (dopo import OK).

  • L’app rileva il file in Download oppure usa Importa file… e seleziona DATI_CIFS.json.
  • I dati (Host, User, Password, Folder, …) sono quelli del JSON: non sono modificabili a mano.
  • Se l’import fallisce: messaggio con istruzioni e riprova (niente digitazione Host/User).
Esito: import riuscito; dati pronti solo per Copia.

Fase 6 — Configurazione CIFS sul Telefono (due step)

Step 6/1 — Spiegazioni e apri/installa CIFS

  • Fase semiautomatica: i dati importati si copiano in CIFS Documents Provider (Play Store / da MediaManager).
  • Checkpoint locale: se CIFS non è installata, messaggio con istruzioni; altrimenti Installa/Apri.
  • Tocca Fatto per passare allo step di copia.

Step 6/2 — Copia campi e Attiva Catalogo

  1. In CIFS: [+] → Input. Torna a MediaManager.
  2. Per ogni campo (Name, Storage, Host, Port, Username, Password, Folder): solo Copia → Incolla in CIFS. Nessun campo editabile in MediaManager.
  3. Salva in CIFS e verifica che la cartella/dispositivo compaia nell’elenco.
  4. Conferma in MediaManager e tocca Attiva Catalogo; seleziona la connessione CIFS (Name = MyMedia) con «Usa questa cartella».
Esito atteso: cartella visibile in CIFS; Catalogo censito correttamente.

Controllo finale

  • Telefono e PC collegati via USB durante i trasferimenti file.
  • I tre file di script sono stati eseguiti dal Desktop senza errori.
  • DATI_CIFS.json della sessione corrente è stato importato.
  • I dati sono stati copiati nei campi CIFS e la risorsa compare in elenco.
  • MediaManager ha attivato il Catalogo.
