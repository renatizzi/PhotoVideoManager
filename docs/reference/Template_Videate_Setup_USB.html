Prima di avviare la procedura verifica e conferma di avere a disposizione:

  • Telefono con l’app MediaManager installata
  • PC/Notebook Windows v. 10 o superiore
  • Cavo USB dati (Trasferimento file / MTP), non solo ricarica

Percorso unico: cavo USB. Il setup del Catalogo non usa Bluetooth.
