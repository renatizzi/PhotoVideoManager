13. Sequenza funzionale ONLY USB (riferimento)

  1. MediaManager genera i file in Download del Telefono.
  2. Utente copia CONFIGURA.CMD, QRCoder.dll, sup.ps1 → Desktop PC via USB.
  3. Utente esegue CONFIGURA.CMD; attende «Tutto pronto»; ottiene DATI_CIFS.json (e no_pw.json).
  4. Utente copia DATI_CIFS.json → Download Telefono.
  5. MediaManager importa DATI_CIFS.json via selettore file.
  6. Utente installa/apre CIFS Documents Provider.
  7. Utente copia i valori in CIFS, salva, verifica elenco; attiva Catalogo in MediaManager.
