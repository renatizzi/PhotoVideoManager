# Guida test 0.16.60 — Nota ter 3 nov

Versione: `0.16.60-preview`

## Critici
1. **Acquisisci cartella con file in radice + sottocartelle:** dopo `+` devono comparire sia la root (se ha media) sia le sottocartelle con media; Conferma deve importare entrambi.
2. **Dettaglio prima di Conferma:** aprire `>` su una cartella appena aggiunta → anteprima foto/video (non messaggio «non contiene»).
3. **Ripristina Cestino:** dopo Pulisci → Utility → Ripristina → Cestino → seleziona → [Ripristina] → i file ricompaiono subito in **Aggiorna**.

## Percorsi / SD
4. Meta Acquisisci/Importa: `Tab … SD \Pictures - 🛜 Online` **senza** «Scheda SD» / «memoria secondaria» / «Memoria principale».
5. Google Drive: `Google Drive \il-mio-drive - 🛜 Online` (niente doppio «Google Drive»).
6. Icona stato sempre presente (🛜 / ⚠ / ?).

## Setup modello
7. Cambiare modello in Setup (es. «Tab S9») → Acquisisci/Dettaglio/Importa mostrano «Tab S9», non il nome sistema precedente.

## Importa Esclusi
8. Titoli file leggibili (non `%3A` / `%2F`).
9. [Ripristina in Importa] → file di nuovo nell’elenco Importa senza nuovo Conferma (se possibile).

## Aggiorna filtri
10. Click ciclico su Tutti / Foto / Video: le righe del dominio passano vuoto → ✓ → X → vuoto.

## Pulisci
11. Descrizione TO-BE; solo titoli con contatori; niente «Catalogo» / «Consigliato da tenere».
12. [Sposta nel cestino] nascosto se niente da spostare.
13. Filtro «Più vecchi»: selezionati i più vecchi (il più recente resta vuoto).
