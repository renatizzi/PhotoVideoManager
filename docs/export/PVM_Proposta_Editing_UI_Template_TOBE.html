0. Incongruenze e punti aperti

  1. Sorgenti §10 testo PDF: dice «selezionare la cartella del Catalogo». Per il Setup Sorgenti deve essere la cartella media da acquisire, non la sede Catalogo. Nei template sotto uso «cartella da censire / da acquisire». Conferma se ok.
  2. Cloud (§7): chiedi chiarimento. Nei template assumo percorso SAF come locale (account già sul dispositivo → scegli cartella; niente «Aggiungi account»). Se serve un flusso diverso, va specificato.
  3. RAPIDA PC/NAS: il PDF dice che manca. Sotto propongo i passi (Host manuale → CIFS → cartella → Salva). PROPOSTA finché non confermi.
  4. GUIDATA su Sorgenti PC/NAS: il PDF chiede di «verificare se opportuno». Nei template Sorgenti uso solo percorso diretto (come landing §10); RAPIDA/GUIDATA restano sul Setup Catalogo. Se vuoi GUIDATA anche sulle sorgenti, lo aggiungo dopo OK.
  5. Esc: nel PDF «valuterei». Nei mock è presente con conferma uscita. Conferma se lo vuoi vincolante.
  6. Stato: il PDF non ribadisce «Non verificabile»; resta Online / Offline / Non verificabile (chiusura Workflow 28/10) dove rilevabile.
  7. Nome Catalogo: default MediaManagerCatalog (niente esempi tipo «Vacanza a Parigi»). Sovrascrive la chiusura 3 precedente.
  8. Setup = sostituzione: niente Imposta/Modifica in ingresso. Se la procedura fallisce resta il Catalogo precedente. Sovrascrive S0 precedente.

3. Dettaglio procedura RAPIDA (proposta — era mancante)

RAPIDA PC (dopo Avvia, default):
1) Pagina Host/User/Password (Host solo manuale) + scheda CIFS con Copia
2) Apri CIFS → Salva connessione → Indietro
3) Scegli cartella (share Catalogo)
4) Controlla i dati e Salva
5) «Configurazione completata correttamente» → ritorno
Non include USB/CONFIGURA/script (quelli sono GUIDATA 1–4).
RAPIDA NAS (dopo Avvia, default):
1) Host/User/Password manuali + CIFS
2) Scegli cartella
3) Salva + conferma
GUIDATA NAS aggiunge solo la checklist preparazione SMB prima del punto 1.
