Setup Catalogo personale — Template pagine e confronto

Documento di allineamento (sola lettura UI) · senza modifiche al codice

Riferimenti: videate congelate (PPT V2 / docs/reference/videate-utente-setup-catalogo-pc.md) · build congelata 0.16.37 (e0e0662) · build attuale 0.16.53 (f1625f0) · nota Setup Catalogo / proposta razionalizzazione F1–F4 (25/10/2026).

Questo documento riporta solo TITOLO, SOTTOTITOLO e DESCRIZIONE (introduzione di pagina) per ogni videata del Setup Catalogo, declinata per dispositivo (W1–W4). Non contiene istruzioni operative a checklist né riferimenti allo stato runtime dell’app.

1. Chrome comune (tutte le videate Setup)

TITOLO: Setup Catalogo personale (fisso su tutte le pagine del Wizard)

Il sottotitolo cambia per pagina. La descrizione è il testo introduttivo sotto il sottotitolo. Le risposte chiuse (combo / Sì-No) compaiono dove indicato sotto «Elementi di pagina», senza elenco operativo.

2. Punto di differenziazione procedura RAPIDA / GUIDATA

Esiste una sola biforcazione, ed è solo sul ramo PC (W2). Non esiste su W1 (questo dispositivo), W3 (Cloud) né W4 (NAS).

2.1 Dove si trova

Dopo il Passo 0 («Dove tenere il Catalogo») con scelta «Su un PC/Notebook Windows», l’attuale 0.16.53 inserisce una pagina intermedia assente nella 0.16.37 e assente nelle videate congelate PPT V2.

TITOLO: Setup Catalogo personale

SOTTOTITOLO: Cartella condivisa già pronta?

DESCRIZIONE: Se la cartella condivisa del Catalogo sul PC è già pronta e la vedi dal tablet (Disco di rete / CIFS), puoi andare subito al collegamento. Altrimenti segui la preparazione guidata (USB e script).

Domanda: La cartella condivisa del Catalogo è già pronta e raggiungibile da questo tablet?

Risposta A — RAPIDA: Sì, vai al collegamento CIFS → salta i Passi 1–4 → entra al Passo 5 (CIFS)

Risposta B — GUIDATA: No, prepara la condivisione → sequenza Passi 1 → 2 → 3 → 4 → 5

3.3 Superfici fuori Wizard (non erano nelle videate Setup PC)

Fuori dal perimetro delle videate Setup Catalogo PC congelate, la 0.16.53 (da 0.16.52 + F4) mostra anche una riga «Posizione del Catalogo» su Dashboard, Organizza, Acquisisci e Aggiorna. Non fanno parte dei template Wizard sotto; sono citate solo per completezza del confronto versione.

4. Template pagine implementate — per dispositivo

Per ogni pagina: TITOLO · SOTTOTITOLO · DESCRIZIONE. Dove la pagina ha una domanda chiusa, è riportata come «Domanda» (non come istruzione operativa).

TITOLO: Setup Catalogo personale

TITOLO: Setup Catalogo personale

DESCRIZIONE: È tutto pronto per lanciare la routine che ti consentirà di creare la cartella dedicata al Catalogo personale. Ecco le istruzioni:

Elementi di pagina (etichette): Doppio clic su CONFIGURA · Conferma UAC · Attesa messaggio «Tutto pronto».

Pagina W2-5 — CIFS (comune a RAPIDA e GUIDATA)

TITOLO: Setup Catalogo personale

SOTTOTITOLO: 5 – Accedere alla cartella del Catalogo mediante CIFS

DESCRIZIONE: L’ultimo passo della procedura prevede la configurazione dell’app denominata CIFS Documents Provider (scaricabile gratuitamente su Google Play). Ecco i dati da inserire: con il bottone «Copia» puoi incollarli uno alla volta sul form di CIFS.

Elementi di pagina (etichette campi scheda, non procedura): ID · Name · Storage · Domain · Host · Port · Enable DFS · User · Password · Folder · azioni Apri CIFS / Attiva collegamento / scelta cartella.

Nota di confronto: in 0.16.37 la scelta cartella aveva sottotitolo proprio «Scegli la cartella del Catalogo»; in 0.16.53 resta sotto lo stesso sottotitolo del Passo 5.

Pagina W2-F — Esito

TITOLO: Setup Catalogo personale

SOTTOTITOLO: Configurazione completata

DESCRIZIONE: Posizione del Catalogo = PC (con riepilogo cartella / condivisione / utente, senza password).

Pagina W4 — Guida

TITOLO: Setup Catalogo personale

SOTTOTITOLO: NAS / disco di rete

DESCRIZIONE: Collega il NAS/disco di rete con CIFS Documents Provider (Host, porta 445, utente, cartella).

Testo di supporto in pagina (non checklist): le credenziali restano in CIFS; MediaManager sceglie solo la cartella. Quando CIFS mostra la cartella, tocca Scegli cartella.

Azione primaria: Scegli cartella / Apri CIFS

Pagina W4 — Esito

TITOLO: Setup Catalogo personale

SOTTOTITOLO: Configurazione completata

DESCRIZIONE: Posizione del Catalogo: Su disco di rete o NAS.

Passi PC 1–5 (sottotitoli numerati PPT) CONFORMI CONFORMI (ramo GUIDATA)

Per valutare le modifiche di 0.16.53 rispetto a ciò che era congelato sulle videate Setup Catalogo: le uniche divergenze strutturali sul Wizard sono (1) la pagina di biforcazione RAPIDA/GUIDATA sul PC e (2) l’accorpamento della scelta cartella sotto il sottotitolo del Passo 5. Il resto dei TITOLO/SOTTOTITOLO del ramo guidato PC coincide con 0.16.37 / PPT V2.

6. Cosa questo documento non include (di proposito)

· Checklist operative passo-passo e testi «come fare»
· Messaggi di stato runtime (raggiungibile / non raggiungibile / recupero IP in corso / bozze)
· Istruzioni di test, installazione APK o procedimento di prova sul tablet
· Modifiche al codice (nessuna in questo turno)
