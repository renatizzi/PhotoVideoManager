0. Punti aperti (prima del codice)

Setup — nome dispositivo: è possibile leggere il nome già impostato dall’utente (es. «Tab S9 di RENATO») e usarlo come default al posto di MyDevice? → proposta mock: sì, se leggibile; altrimenti MyDevice.
Cloud — dettaglio lento: c’è un modo per velocizzarlo? → da analizzare (cache listing / lazy miniature); non mockato come UI.
Importa scarti: non riproporre i file scartati a ogni [Conferma] se si mantengono gli originali. → regola di esclusione persistente (come BL-15); da confermare.
BUG 1: alcuni file importati (es. .mp4) non riconosciuti — da approfondire in fase implementativa, non in template.
