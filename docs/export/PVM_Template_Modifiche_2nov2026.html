5. Domande e bug — senza schermata nuova

  1. Dettaglio cartella su Cloud lento. Resta una domanda: c’è un modo per velocizzarlo? Nessun cambio di layout in questo template.
  2. File scartati in Importa. Se si tengono gli originali, i file scartati non devono ricomparire a ogni Conferma. Manca ancora la regola su dove ricordare lo scarto. Nessuna schermata aggiunta.
  3. File importati non riconosciuti (esempio estensione mp4). Bug da approfondire, non è una modifica di pagina.
  4. Nome dispositivo in prima pagina. Il mock usa il nome letto dal dispositivo solo se quella lettura è possibile.
