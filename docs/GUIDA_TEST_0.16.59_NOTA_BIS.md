# Guida test 0.16.59 — Nota bis 2 nov

Versione: `0.16.59-preview`

## Setup Catalogo
1. Avvio procedura su dispositivo con nome di sistema leggibile.
2. Verificare che «Qual è il modello del dispositivo?» mostri quel nome (non `MyDevice`).

## Acquisisci
1. Elenco cartelle: ogni riga ha **dispositivo** (blu bold corsivo) + meta `SD? \path - stato`.
2. Niente riga «Questo tablet: … (tocca per rinominare)».
3. Badge **SD** solo su memoria Secondaria di telefono/tablet (mai su Cloud/NAS/PC).

## Importa / Esclusi
1. Deselezionare alcuni file → IMPORTA: non riproposti al Conferma successivo.
2. Sezione **Esclusi**: «Ripristina in Importa» → al prossimo Conferma tornano candidati.
3. Righe media: nome file blu bold corsivo + meta Catalogo (device [,SD] \path - stato).

## Aggiorna
1. Filtri Tutti/Foto/Video filtrano l’elenco; ciclo ✓/X/vuoto resta sul sottoinsieme visibile.
2. Formato riga allineato al Catalogo.

## Pulisci
1. All’ingresso: analisi automatica (niente bottone «Analizza duplicati»).
2. Sottotitolo / descrizione TO-BE; **Indietro** → Aggiorna.
3. Scarti: selezione manuale; Duplicati: chip Più vecchi / Più recenti + override.
4. **Sposta nel cestino** conferma unica.

## mp4
1. Importare un `.mp4` (anche con MIME atipico): deve comparire come video in Importa/Aggiorna.

## Fuori scope
Visibilità altri dispositivi dal telefono (filiera) — approccio nuovo, turno successivo.
